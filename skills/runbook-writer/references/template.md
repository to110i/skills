# 手順書テンプレート

この構成をベースにする。小規模な作業では節を統合・省略してよいが、「事前確認」「各手順の期待結果」「ロールバック」は必ず残す。`{{ }}` は書き換える部分。

表に入れるか、見出し付きの手順にするかの基準：
- **1行のコマンドで、期待結果も1行で言える** → 表の1行にする（事前確認・事後確認の多くはこれ）
- **複数行のコマンド、または ⚠️ が付く変更操作** → `### 手順N.` の見出しを立ててコードブロックにする
